# Auto Miner (Fabric, Minecraft 26.1.2, имена Mojang)

Клиентский мод. Нужны JDK 25 и Gradle 9.x.

## Использование
- Включить/выключить: написать в чат `.miner` (на сервер не отправляется).
- В хотбаре: кирка на Эффективность, кирка на Шёлковое касание, меч (или топор), еда.
- Туннели 1x2 копаются Эффективностью, алмазная руда только Шёлком.
- Обходит лаву, гравий/песок над туннелем, бедрок; бьёт мобов рядом (кроме эндерменов);
  ест при голоде <= 14; выбрасывает мусор (булыжник, глубинный сланец, кремень и т.д.).
- Предметы с остатком прочности <= 10 не используются.
- Выключается при здоровье < 4 сердец, при горении, при неизвестном уроне, при Вардене, если застрял.
- Настройки находятся в начале AutoMinerLogic.java.

## Сборка
1. Распакуйте архив, откройте терминал в папке проекта.
2. Один раз сгенерируйте wrapper: `gradle wrapper --gradle-version latest`
   (или скопируйте `gradlew`, `gradlew.bat` и папку `gradle/wrapper` из официального Fabric Example Mod).
3. `./gradlew build` (Windows: `gradlew.bat build`)
4. Готовый мод: `build/libs/auto-miner-1.0.0.jar`

Если Gradle не находит версию Loom / Fabric API, обновите значения в `gradle.properties`
по данным https://fabricmc.net/develop
